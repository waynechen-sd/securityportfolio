## English

This repository contains a de-identified, method-led security delivery portfolio.

It is designed to showcase how I translate fragmented information, unclarified requirements, and collaboration gaps into verifiable control baselines and actionable next steps, along with my working mindset.

The public website is hosted via `index.html`, which features complete bilingual content in both English and Traditional Chinese.

## Structure

```text
├── index.html                 # Public bilingual portfolio site
├── docs/                      # Detailed bilingual case notes
├── assets/
│   ├── css/                   # Site styles
│   ├── js/                    # Language-switch behavior
│   └── images/
│       ├── illustrations/     # Method diagrams and visual variants
│       ├── cases/             # Homepage field-case visuals
│       └── supporting/        # De-identified supporting artifacts
└── .gitignore
```
