# Image assets

This folder separates the visuals used by the portfolio into three groups.

## `illustrations/`

De-identified method diagrams used to explain the workflow and its stages. The `*-alternative.jpeg` files are retained design variants for future iteration.

## `cases/`

De-identified visual summaries used by the public homepage for the three field cases:

- Evidence correlation
- POC delivery
- Decision-ready data

## `supporting/`

Supporting artifacts connected to the detailed Markdown case notes. They are included to show the working context behind the methods.

All artifacts are published as de-identified portfolio material. Client names, personal identifiers, and confidential configuration details have been removed. The material is presented to explain working methods and delivery outputs, not to reproduce a customer environment or disclose source documentation.
